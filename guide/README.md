# Study guide

Ten short modules, grouped by the exam's three competencies. Each takes 3 to 7 minutes and has the same shape, so your brain knows what's coming:

1. **TL;DR**: the 3 things to remember, in 30 seconds
2. **The details**: tables and short bullets, no walls of text
3. **Exam traps**: what people get wrong
4. **Quick check**: click to reveal the answers

> [!TIP]
> Short on time? Start with **Competency 3**. It's 42% of the exam. Read one module, then run **Learn** on it in the [study website](https://unkwncokonut.github.io/wgu-d426-study-guide/#guide). Then take a break.
