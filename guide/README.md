# Study guide

Ten short modules. Each one takes 3 to 6 minutes and has the same shape, so your brain knows what's coming:

1. **TL;DR**: the 3 things to remember, in 30 seconds
2. **The details**: tables and short bullets, no walls of text
3. **Exam traps**: what people get wrong
4. **Quick check**: 3 questions; click to reveal the answers

> [!TIP]
> Don't read these in order in one sitting. Pick one, read it, then run **Learn** on that topic in the [study website](https://unkwncokonut.github.io/wgu-d426-study-guide/#guide). Then take a break.
